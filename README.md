# Movie Recommender (Flask + Content-Based ML)

## Run locally
```bash
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
# put tmdb_5000_movies.csv and tmdb_5000_credits.csv in data/
python build_model.py         # creates model.pkl + similarity.pkl
python app.py                 # open http://localhost:5000
```

## Docker
```bash
docker build -t movie-recommender .
docker run -p 5000:5000 movie-recommender
```

## Files
- `analysis.ipynb` – data cleaning, features, similarity, testing, bonus ideas
- `build_model.py` – same pipeline as a script
- `app.py` – Flask app (`/` and `/recommend`)
- `model.pkl`, `similarity.pkl` – generated by the notebook/script
